# 模板范围与隐私

保留：界面、双语、记录模型、校验、项目与任务逻辑、像素 SVG 物件、思源宋体和许可、本地 D1 模拟存储、备份恢复、MCP 本地桥与自动检查。

移除：原作者初始工作待办、公司和项目树、饮食和旅行记录、真实品牌图片和摄影、个人外链、固定姓名、原始 Sites 项目身份、历史数据库、导出包、密钥、一次性迁移脚本。

首次初始化不写入任何记录。个人身份标签在 lib/config.ts；开发登录固定为 local_workspace，仅供本机隔离使用。

测试和 examples/ 下的输入为虚构测试夹具，不是初始记录。单元测试使用内存数据库，不写使用者的日常数据库。

该仓库独立于作者私人工作站；不会自动同步作者的网站或数据库。对自己的模板副本更新代码，不等于替换数据库。
